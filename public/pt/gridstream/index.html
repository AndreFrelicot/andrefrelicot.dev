GridStream

Assista a até doze vídeos ao mesmo tempo no iPad, servidos pelo seu Mac pela rede local. Sem conta, sem nuvem, nenhum dado coletado.

1. O servidor para Mac

O GridStream Server varre suas pastas de vídeo (.mp4, .m4v, .mov) e as transmite para o iPad. Ele fica na barra de menus.

Baixar para Mac

GridStream 1.0 · imagem de disco assinada e notarizada pela Apple · 23,6 MB · macOS 15.6 ou posterior

2. O app para iPad

Gratuito na App Store, para iPadOS 17 ou posterior. Ele encontra o seu Mac na rede local.

Para começar

  1. Abra o GridStream Server no Mac e adicione uma ou mais pastas de vídeo.
  2. Abra o GridStream no iPad, na mesma rede: ele encontra o Mac sozinho.
  3. Digite o PIN mostrado no menu do servidor, na barra de menus.
