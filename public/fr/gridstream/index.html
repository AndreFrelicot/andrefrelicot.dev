GridStream

Regardez jusqu'à douze vidéos à la fois sur iPad, servies par votre Mac sur le réseau local. Pas de compte, pas de cloud, aucune donnée collectée.

1. Le serveur Mac

GridStream Server scanne vos dossiers vidéo (.mp4, .m4v, .mov) et les diffuse à l'iPad. Il vit dans la barre des menus.

Télécharger pour Mac

GridStream 1.0 · image disque signée et notarisée par Apple · 23,6 Mo · macOS 15.6 ou plus récent

2. L'app iPad

Gratuite sur l'App Store, pour iPadOS 17 ou plus récent. Elle trouve votre Mac sur le réseau local.

Pour commencer

  1. Ouvrez GridStream Server sur le Mac et ajoutez un ou plusieurs dossiers vidéo.
  2. Ouvrez GridStream sur l'iPad, sur le même réseau : il trouve le Mac tout seul.
  3. Saisissez le code PIN affiché dans le menu du serveur, dans la barre des menus.
